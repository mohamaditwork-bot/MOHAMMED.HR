# MOHAMMED.HR
لوحة التحكم للموارد البشرية — نوفوتيل المدينة المنورة

موقع على Netlify يعرض بيانات ملف الإكسل (الموظفين، العقود، الإقامات، الجوازات، رخص العمل، الصحية، التابعين، الخروج والعودة، مطابقة المنصات، التأمين الطبي، العمالة) بعد تسجيل الدخول.

- **لا توجد أي بيانات موظفين في هذا المستودع.** البيانات والمستخدمين محفوظة في Netlify Blobs، ولا تُرسل إلا بعد تسجيل الدخول.
- المدير يرفع ملف الإكسل المحدّث من صفحة **الإدارة** داخل الموقع، ويضيف/يعدّل المستخدمين.
- المتبقي (يوم) والحالة تُحسب تلقائيًا من تاريخ اليوم وحدود التنبيه في ملف الإكسل.

## متغيرات البيئة (Netlify)
- `SESSION_SECRET` — نص عشوائي طويل لتوقيع الجلسات.
- `HR_USERS_SEED` — (اختياري) JSON لمستخدمين أوليين `[{id,name,role,hash}]` بكلمات مرور مشفّرة scrypt.

## البنية
- `public/` — صفحة الدخول واللوحة.
- `netlify/functions/` — `login`, `logout`, `me`, `data`, `upload`, `users`, `password`.
- `netlify/lib/` — المصادقة وتحليل ملف الإكسل.
